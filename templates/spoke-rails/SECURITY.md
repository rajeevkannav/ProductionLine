# Security Policy

Report vulnerabilities privately via GitHub **Security Advisories** on this repository rather than public issues.

Automated PRs generated by **ProductionLine (`mogra`)** are gated before merge by:

- Protected-path checks (automated PRs cannot modify `.github/workflows/` or `.mogra.yaml`)
- Least-privilege workflow permissions (`permissions: {}` by default, granted per job)
- Gitleaks secret scanning
- Brakeman (Rails SAST), `bundler-audit`, and `npm audit`
- CodeQL (`actions`, `ruby`, `javascript-typescript`)
- CycloneDX SBOM generation

Runtime secrets (`RAILS_MASTER_KEY`, provider API keys) live only in Render environment variables or GitHub Secrets and are never committed.
