# Evidence-First Reporting

- **Never fabricate or extrapolate** test counts, Lighthouse scores, or coverage numbers.
- Every PR body and Issue status comment generated by `mogra` must include an **Evidence Ledger** containing:
  1. Exact commands executed and exit codes.
  2. Observed unit, E2E, `axe-core`, and `320px` reflow measurements.
  3. SBOM and security scan statuses (or `NOT RUN` if skipped).
